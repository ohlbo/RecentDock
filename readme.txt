# 项目计划：RecentDock

## 一、项目定位

一个独立的、开源、轻量的 Windows 桌面常驻面板，专门展示最近打开的文件和访问过的文件夹，混合按时间倒序排列。

不依赖任何第三方桌面整理工具，不整理桌面图标、不接管桌面、不修改系统设置，只往桌面上放一个只读的最近项列表窗口。

**核心差异点**：完全绕开系统“显示最近打开的项目”UI 开关，直接读取 Recent 目录原始数据，自主解析、过滤、展示。

## 二、技术选型

| 项目 | 选择 |
|---|---|
| 语言 | C# (.NET 8) |
| UI 框架 | WPF |
| 快捷方式解析 | `IShellLink` COM 接口（自行封装） |
| 目标验证 | `File.Exists` / `Directory.Exists` |
| 进程模型 | 单进程、常驻托盘 |

## 三、功能模块与实现方式

### 模块 1：数据采集（RecentScanner）

**功能**：遍历 Recent 目录，解析每个 `.lnk`，产出结构化记录。

**实现方式**：
1. 通过 `SHGetSpecialFolderPath(CSIDL_RECENT)` 获取 Recent 目录路径。
2. 用 `Directory.EnumerateFiles` 筛选 `.lnk` 文件。
3. 对每个 `.lnk`，用 `IShellLink.GetPath()` 解析出目标真实路径。
4. 用 `File.Exists` / `Directory.Exists` 验证目标是否有效。
5. 用 `File.GetAttributes` 判断目标是文件还是文件夹。
6. 取 `.lnk` 文件的 `LastWriteTime` 作为“最近访问时间”的近似值。
7. 过滤掉解析失败、目标不存在、以及指向系统垃圾的记录。

**输出**：`RecentItem` 列表，字段：`DisplayName`、`TargetPath`、`IsDirectory`、`LastAccessTime`。

### 模块 2：过滤规则（FilterEngine）

**功能**：在数据采集基础上应用可配置过滤规则。

**实现方式**：
- **白名单扩展名**：默认保留常见文档类型（pdf、doc、docx、xls、xlsx、ppt、pptx、txt、md、图片等），可配置。
- **黑名单路径**：过滤掉 `%Temp%`、`Windows\` 等系统目录下的记录。
- **去重**：同一目标路径只保留最新一条。
- **数量上限**：默认保留最近 50 条，可配置。

### 模块 3：实时刷新（Watcher）

**功能**：监听 Recent 目录变化，自动刷新面板。

**实现方式**：
- 使用 `FileSystemWatcher` 监听 Recent 目录的 `Created` / `Changed` / `Deleted` 事件。
- 事件触发后加防抖延迟（如 500ms），避免批量操作时频繁刷新。
- 刷新时重新执行模块 1 + 模块 2，更新 UI。

### 模块 4：UI 展示（DockPanel）

**功能**：常驻桌面的面板窗口。

**实现方式**：
- **窗口样式**：无边框、半透明背景、可拖动、可调整大小。
- **贴桌面**：通过 `SetParent` 挂到桌面层，实现“显示桌面”时不被隐藏。
- **列表展示**：每项显示图标 + 文件名 + 类型标识（文件/文件夹）+ 相对时间。
- **交互**：单击打开目标；右键菜单支持“从列表移除”“打开所在位置”。
- **空状态**：无记录时显示提示文案。

### 模块 5：配置与托盘（Config & Tray）

**功能**：托盘控制与配置持久化。

**实现方式**：
- 托盘图标，右键菜单：显示/隐藏面板、设置、退出。
- 配置文件（JSON）保存：白名单扩展名、数量上限、面板位置和大小、开机自启。
- 开机自启通过注册表 `Run` 键实现，可选项。

## 四、技术风险与对策

| 风险 | 对策 |
|---|---|
| 部分 `.lnk` 解析失败（无目标路径） | 捕获异常，跳过该条记录，不中断流程 |
| Recent 目录记录时间不准确 | `.lnk` 的 `LastWriteTime` 是近似值，可接受；如需精确，可读注册表 `RecentDocs` 作为补充 |
| `SetParent` 到桌面层后窗口可能被遮挡 | 设置合适 `Z-order`，或提供“总在最前”选项 |
| 杀毒软件误报（调用 COM + 常驻） | 开源代码、不写敏感注册表、不注入进程 |

## 五、项目边界（明确不做的事）

- 不做桌面图标整理、不接管桌面图标。
- 不做快捷键呼出的启动器。
- 不修改系统“最近打开项目”的任何设置。
- 不读取、不上传任何用户数据（纯本地）。
- 不依赖任何第三方桌面整理工具。
